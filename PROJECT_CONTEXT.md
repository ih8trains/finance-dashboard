## Текущая проблема дашборда
- `index.html` всё ещё использует `API_URL` Google Apps Script.
- `loadDashboard(pass)` вызывает `api({})`, получает все строки и настройки из Apps Script. Поэтому вход зависит от Google Sheets/GAS и медленный.
- В HTML уже есть UI/код управления архивами, manifest и AES-GCM/PBKDF2; однако обычная авторизация и загрузка основного дашборда пока не переведены на чтение существующих GitHub-архивов.
- Цель: после ввода пароля браузер читает manifest и месячные зашифрованные архивы с GitHub Pages/raw URL, расшифровывает их локально, строит дашборд без запроса к Google Sheets. Добавить разумный локальный кэш, не сохраняя пароль в открытом виде.
- Затем проверить редактирование ручной разметки, правила, бюджет/настройки и их сохранение. Только после проверки отключать/удалять старую инфраструктуру Google Sheets/GAS.

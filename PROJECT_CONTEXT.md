## Текущая проблема дашборда
- `index.html` всё ещё содержит `API_URL` Google Apps Script.
- `loadDashboard(pass)` вызывает `api({})`, получает все операции/labels/settings из Apps Script. Поэтому вход зависит от Google Sheets/GAS и медленный.
- Функции `saveLabel`, `saveMeta`, `flushPendingLabels` тоже отправляют изменения в Apps Script.
- Код архивирования в HTML предназначен для создания/пересборки архивов из Google Sheets, а не для обычного чтения архива при входе.
- Кнопка «Создать и проверить архивы» сейчас не имеет рабочего обработчика. Кнопка «Пересоздать все архивы» вызывает `runArchiveRebuild` и читает Google Sheets. Не нажимать её: архивы уже созданы.
- Обычный вход пока не использует `data/manifest.json` и архивы GitHub.

## Целевое поведение
1. Пользователь вводит пароль.
2. Браузер загружает `data/manifest.json` и нужные месячные `.json.enc` файлы с GitHub Pages/raw.githubusercontent.com.
3. Проверяет метаданные, расшифровывает AES-GCM через Web Crypto и сверяет SHA-256/count.
4. Строит дашборд без запроса к Google Sheets и Apps Script.
5. Добавить локальный кэш расшифрованных данных/разметки, не хранить пароль открытым текстом.
6. Перевести сохранение пользовательской разметки/настроек на выбранное безопасное хранилище и проверить повторный вход.
7. Только после полной проверки отключать старую GAS-инфраструктуру и обсуждать удаление листов.
